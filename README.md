# Emily in Paris English Lesson

Standalone interactive English lesson based on the generated Paris lesson, with its activities, styling, and in-page interactions kept intact.

## Preview locally

Open `index.html` in a modern browser. The lesson’s Google Fonts require an internet connection; the rest of the lesson is included in the HTML file.

## Publish with GitHub Pages

The included GitHub Actions workflow deploys this folder when changes are pushed to the `main` branch. In the repository settings, enable **Settings → Pages → Build and deployment → GitHub Actions**.
